# ADR-008 — Un solo lanzamiento completo

- Fecha: 2026-10-20 · Estado: Aprobado (instrucción del usuario)

## Decisión
No hay "fase 2": todo el alcance de `CLAUDE.md` sale en el lanzamiento. El tiempo no es la restricción; la completitud y la calidad sí. El trabajo se organiza en etapas con agentes en paralelo y puertas de calidad (`docs/etapas.md`).

## Consecuencias
Las tareas no se recortan para cumplir fechas; si algo no pasa su puerta, la etapa no cierra.
